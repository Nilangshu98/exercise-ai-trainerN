Extending the app

New exercises need one entry in python/exercise_rules.py describing which joint angles define correct form (a squat needs knee + back angle, a plank needs back angle, etc.), plus a dataset/<name>/correct/ and /incorrect/ folder with sample jpg/png/mp4/avi files. Restart the server and it shows up here automatically. See the README for a copy-paste template.
